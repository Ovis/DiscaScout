# DISCAS Rental History Exporter

DISCASの「DVD/CDレンタル履歴」を、DiscaScoutのレンタル履歴インポート用JSONへ変換するローカルChrome拡張。

## 使い方

1. ChromeでDISCASへログインする
2. 「DVD/CDレンタル履歴」ページを開く
3. `chrome://extensions/` でデベロッパーモードを有効にする
4. 「パッケージ化されていない拡張機能を読み込む」からこのディレクトリを選択する
5. 拡張を開き「取得開始」を押す
6. 完了後、JSONをコピーまたはダウンロードしてDiscaScoutの運用画面からインポートする

## 取得方針

- 履歴ページから総件数・総ページ数を毎回取得し、ページ数を固定値として扱わない
- ページは直列に取得し、最低2秒間隔を空ける
- 10ページごとに追加で5～20秒のランダム待機を入れる
- ページ取得失敗時は10秒、30秒、60秒待って最大3回Retryする
- 全履歴行数を重複排除前に数え、DISCAS表示の総件数と一致した場合だけ正常結果として保存する
- CDだけを抽出し、最終結果は`titleId`で重複排除する
- 同一`titleId`でタイトル・アーティストが異なる場合は最初の値を採用し、診断情報に不一致を残す
- Cookie、ユーザー名、パスワードは保存・出力しない

取得中の状態は`chrome.storage.local`へページ単位で保存する。Service Workerの停止からは次ページを継続し、ユーザーが中止後に「再開」した場合はページ境界の変化による取りこぼしを防ぐため1ページ目から再走査する。

新しい取得が失敗しても、前回正常取得した結果は保持する。完全性チェックに失敗した結果は通常のインポート用JSONとして扱わず、ページ別件数などを含む診断JSONだけを出力できる。
